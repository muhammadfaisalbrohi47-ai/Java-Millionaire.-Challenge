# 🎮 Java Millionaire Challenge

A console-based quiz game developed in Java using Object-Oriented Programming (OOP) concepts.

## 📌 About the Project

Java Millionaire Challenge is inspired by the popular quiz show *Who Wants to Be a Millionaire?*

Players answer 10 multiple-choice questions to win virtual prize money. The game includes three special lifelines to make the experience more interactive.

This project was developed as a university assignment for learning and demonstrating Java programming and OOP concepts.

## ✨ Features

- 👤 Player name registration
- ❓ 10 multiple-choice questions
- 💰 Prize money for correct answers
- 50:50 Lifeline – Removes two incorrect options
- 📊 Audience Poll – Simulates audience voting
- 📞 Phone a Friend – Provides a simulated suggestion
- 🚪 Quit option
- 🏆 Final score and prize display
- 🔒 Guaranteed prize after five correct answers

## 🛠️ Technologies Used

## 🧠 OOP Concepts

This project demonstrates:

1. **Encapsulation:** Private variables and public methods.
2. **Abstraction:** Question interface.
3. **Polymorphism:** Method overriding and interface implementation.
4. **Interface-based inheritance:** QuizQuestion implements Question.

## ▶️ How to Run

### Requirements

- Java JDK installed.
- Visual Studio Code or another Java IDE.

### Step 1: Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/Java-Millionaire-Challenge.git
```

### Step 2: Open the Project Folder

```bash
cd Java-Millionaire-Challenge
```

### Step 3: Compile the Java Files

```bash
javac Main.java Game.java Player.java QuizQuestion.java
```

### Step 4: Run the Game

```bash
java Main
```
